# A Rahman Riful — Personal Professional Website

This is a responsive, bilingual (English/Bangla) personal portfolio website.

## Included
- Personal profile and uploaded photographs
- About, experience, expertise and destination sections
- Visa Success Stories area (ready for approved stories to be added)
- Client review form that prepares an email for manual review
- WhatsApp, phone, email, Facebook and LinkedIn contact links
- Mobile-friendly layout
- No Bright Holidays logo or agency branding; this is a personal website

## Important notes
1. The website is static and suitable for free GitHub Pages hosting.
2. The review form opens the visitor's email application and prepares a review email. It does not save reviews automatically. A form/backend service would be needed for automatic online submissions.
3. Success stories are currently an empty section. Add only genuine cases and publish client documents only with written permission. Hide passport numbers, dates of birth, application IDs and other personal details.
4. No CV file was supplied, so this version does not invent education, past employers or qualifications. Add a verified CV file once it is ready.
5. The website states that visa outcomes are decided by the relevant authorities and are not guaranteed.

## Publish on GitHub Pages
1. Create a GitHub account at https://github.com/
2. Create a new public repository named `yourusername.github.io` (replace `yourusername` with your GitHub username).
3. Extract this ZIP file.
4. Upload the contents inside the folder (not the outer folder itself) to the repository's root. Keep `index.html`, `style.css`, `script.js`, and the `assets` folder together.
5. In repository Settings → Pages, select Deploy from a branch, choose `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish. The address will be `https://yourusername.github.io/`.

You can follow the publishing steps with assistance; do not share your GitHub password or verification codes.
